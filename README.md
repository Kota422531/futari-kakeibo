# ふたりの家計簿

スマホで使う、ふたり用の家計簿です。GitHub Pages で公開し、データは Firebase(Cloud Firestore)に保存します。ログインは不要で、共有リンクを知っているふたりだけが読み書きできます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組みとデザイン |
| app.js | アプリ本体(記録・集計・共有・レシート読み取り) |
| calc.js | 集計の計算ロジック |
| config.js | Firebase の接続設定(ここだけ書き換えます) |
| firestore.rules | Firestore のセキュリティルール(Firebase コンソールに貼り付けます) |
| apple-touch-icon.png / icon-512.png | ホーム画面用アイコン |

config.js が空のままでも、「この端末だけに保存するお試しモード」で動きます。

---

## 1. Firebase を準備する(約10分)

1. https://console.firebase.google.com で「プロジェクトを作成」をクリックします。名前は例えば `futari-kakeibo` にします。Google アナリティクスはオフで構いません。
2. 左メニューの「Firestore Database」から「データベースを作成」を選びます。
   - ロケーションは `asia-northeast1(東京)` を選びます。
   - 開始モードは「本番環境モード」を選びます。
3. Firestore の「ルール」タブを開きます。中身をすべて消して `firestore.rules` の内容を貼り付け、「公開」を押します。
4. プロジェクトの概要(歯車 → プロジェクトの設定)を開き、「マイアプリ」でウェブ(`</>`)を選んでアプリを登録します。Hosting のチェックは不要です。
5. 表示された `firebaseConfig` の中身(apiKey〜appId)を、`config.js` の `firebase: { ... }` に貼り付けます。

## 2. GitHub Pages で公開する(約5分)

1. GitHub で新しいリポジトリ `futari-kakeibo` を作ります。無料プランで Pages を使うには Public にする必要があります。家計のデータはリポジトリには入らず Firebase 側に保存されるので、公開されるのはプログラムだけです。
2. 「Add file → Upload files」から、このフォルダのファイルをすべてアップロードします。
3. Settings → Pages を開き、「Deploy from a branch」で `main` / `/(root)` を選んで保存します。
4. 1〜2分待つと、`https://kota422531.github.io/futari-kakeibo/` で開けるようになります。

### おすすめ:API キーに制限をかける
Firebase の apiKey は秘密の値ではありませんが、使える場所を絞っておくと安心です。

1. Google Cloud コンソールで「API とサービス → 認証情報」を開き、Browser key を選びます。
2. 「アプリケーションの制限」を「ウェブサイト」にします。
3. `https://kota422531.github.io/*` を追加します。

## 3. ふたりで共有する

1. 滉太さんのスマホで公開 URL を開き、「新しくはじめる」を押します。
2. 「設定 → ふたりで共有する → リンクを送る」で、LINE などから知香さんにリンクを送ります。
3. 知香さんはそのリンクを開きます。同じ家計簿が表示されます。
4. ふたりとも「設定 → この端末で使う人」で自分を選びます。これで、記録時の「支払った人」が最初から自分になります。
5. ホーム画面に追加すると、アプリのように使えます。必ず共有リンクを開いた状態で追加してください。
   - iPhone:Safari の共有ボタン →「ホーム画面に追加」
   - Android:Chrome のメニュー →「ホーム画面に追加」

ホーム画面から開いて「はじめる」画面が出た場合は、受け取ったリンクを「受け取ったリンクで参加する」に貼り付けてください。

### 共有リンクの扱い
共有リンクの末尾 `#h=…` は、家計簿の鍵の役割をします。ふたり以外には送らないでください。万一漏れた場合は、「設定 → この端末の接続を解除」を押してから「新しくはじめる」で新しい家計簿を作り直してください。古いデータは引き継がれません。

## 4. レシート読み取りを使う(任意)

Firebase AI Logic(Gemini)を使います。無料枠の範囲で動きます。2026年7月以降は、設定の途中で App Check(不正利用の防止)の登録を求められます。

1. Firebase コンソールで「AI Logic」を開き、「始める」から Gemini Developer API を選びます。
2. 案内に従って App Check を設定します。
   - reCAPTCHA Enterprise のサイトキーを作ります。ドメインには `kota422531.github.io` を登録します。
   - そのサイトキーをウェブアプリに登録します。
3. `config.js` の `receipt` を次のように書き換えて、アップロードし直します。

```js
receipt: {
  enabled: true,
  model: "gemini-3.5-flash",
  recaptchaSiteKey: "作ったサイトキー"
}
```

記録画面に「レシートを撮って読み取る」が出れば完了です。読み取った金額・日付・店名は入力欄に入るだけで、写真は保存しません。読み取りがうまくいかない場合は、`model` の名前が AI Logic の対応モデル一覧にあるかを確認してください。

## 無料枠の目安

Firestore の無料枠(Spark プラン)は、1日あたり読み取り5万回・書き込み2万回です。ふたりで毎日使っても十分収まります。

## 更新するとき

ファイルを GitHub にアップロードし直すだけで反映されます。スマホ側で古い画面が出る場合は、数分待ってから開き直してください。データは Firebase 側にあるので、更新しても消えません。
